# Xtrim

**Community fitness and activity**

Xtrim is a community fitness app that brings activity tracking together with clubs, events, and challenges.

## Project scope

- Activity recording and progress
- Clubs and group activities
- Community features for shared goals and events

**Technology:** Flutter and Dart, Supabase and PostgreSQL.
